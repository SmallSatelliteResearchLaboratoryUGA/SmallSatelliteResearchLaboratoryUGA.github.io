# UGA Small Satellite Research Laboratory Website

The official website for the [Small Satellite Research Laboratory](https://smallsat.uga.edu) at the University of Georgia. A Next.js 16 static export deployed to GitHub Pages.

## Quick Links

- **Live site:** https://smallsat.uga.edu
- **Admin docs:** Read [ADMIN_GUIDE.md](ADMIN_GUIDE.md) to update members and alumni
- **Architecture:** See [TEAM_SYNC_README.md](TEAM_SYNC_README.md) for how the team sync system works
- **Developer docs:** See [CLAUDE.md](CLAUDE.md) for project setup and conventions

## For Lab Admins

You don't need to touch this repo or any code. To update the members list, alumni list, or team photos:

1. Open the [Google Sheet](https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID) (ask the lab director for the link)
2. Add, edit, or remove rows as needed
3. Click **🚀 Publish to Website**
4. The site updates automatically within 1-2 minutes

See [ADMIN_GUIDE.md](ADMIN_GUIDE.md) for detailed instructions.

## For Developers

### Setup

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # produces ./out (static export)
npm run lint
```

### Project Structure

```
app/              # Next.js App Router (React Server Components + Client Components)
├── page.tsx      # Home page
├── about/        # Who We Are (current members & team)
├── alumni/       # Alumni list
├── missions/     # Mission details
├── software/     # Software projects
├── partners/     # Partner logos
└── ...

public/
├── images/       # Photos, logos, backgrounds
├── json/         # team.json (generated by sync-team.mjs), media.json, etc.
└── CNAME         # Custom domain config

scripts/
└── sync-team.mjs # Syncs team data from Google Sheet CSV to team.json

.github/workflows/
├── deploy.yml    # Builds static export, deploys to GitHub Pages (triggers on push to development)
└── sync-team.yml # Syncs team data from Google Sheet (triggers on Publish button, schedule, or manual)
```

### Tech Stack

- **Framework:** Next.js 16 (App Router)
- **React:** 19.2
- **Styling:** Tailwind CSS v4 + shadcn-ui + Radix UI
- **Animation:** Motion (Framer Motion successor)
- **Icons:** Lucide React
- **Graphics:** OGL (WebGL library)

### Branch Workflow

- **`development`** — Working branch. All source changes go here. Pushing here triggers the deploy.
- **`master`** — Frozen snapshot of the legacy Jekyll site. Do not commit to it.

### Deployment

Pushes to `development` trigger [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml), which:
1. Runs `npm run build` (static export)
2. Uploads `out/` to GitHub Pages

The site is configured for static export (`output: "export"` in [next.config.ts](next.config.ts)), so there is no server runtime. Images are unoptimized for GitHub Pages compatibility.

GitHub Pages source must be set to "GitHub Actions" in repo settings (Settings → Pages). The custom domain `smallsat.uga.edu` is configured via [public/CNAME](public/CNAME).

### Team & Alumni Data

Member and alumni data lives in [public/json/team.json](public/json/team.json) (generated automatically by the sync system). Do not edit this file directly; it is regenerated on every sync.

To test locally:

```bash
export TEAM_SHEET_CSV_URL="https://docs.google.com/spreadsheets/d/.../export?format=csv&gid=0"
node scripts/sync-team.mjs
npm run dev
```

See [TEAM_SYNC_README.md](TEAM_SYNC_README.md) for architecture details.
